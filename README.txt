1. 概要
  WIB-GUI は、Windows 標準のシステムイメージ作成コマンド
  （C:\Windows\System32\wbadmin.exe）を、初心者やスクリーンリーダー
  利用者でも安全かつ分かりやすく操作できる、レジストリ不要・
  単一実行ファイル構成のポータブル Win32 GUI ツールです。

2. 主な機能
  - バックアップ作成（タブ1）:
    固定ドライブ一覧（DRIVE_FIXED）から対象ドライブを複数選択できます
    （システムドライブは既定でチェック済み）。
    保存先としてローカル NTFS ドライブ、またはネットワーク共有フォルダ
    （\\Server\Share + 任意の資格情報）を指定できます。
    実行前に「対象と保存先の同一ドライブ」「同一物理ディスク」「非NTFS」を
    自動検出し、実行コマンドプレビュー（パスワードマスク表示）と
    「いいえ」既定の確認ダイアログを表示します。
    バックアップ実行中は SetThreadExecutionState によりスリープを抑止し、
    進捗率・実行ログをリアルタイム表示します。中断時は
    wbadmin stop job -quiet で安全に停止します。

  - 既存バックアップ確認（タブ2）:
    指定した保存先にある作成済みシステムイメージ（wbadmin get versions）を
    日本語・英語 OS 両対応で解析して一覧表示します。
    「バックアップタブの保存先を反映」ボタンで保存先設定を取り込み、
    取得したバージョン識別子のコピーや「復元手順・印刷」タブへの
    ワンクリック反映が可能です。

  - 復元手順・印刷（タブ3）:
    稼働中の Windows 上からは OS 本体の復元ができない旨の重要注意、
    WinRE GUI ウィザード手順、diskpart list volume によるドライブレター
    確認と wbadmin start sysrecovery コマンド手順、.vhdx マウントによる
    個別ファイル復元手順、BitLocker 回復キーの注意を表示します。
    復元手順は UTF-8（BOM付き）テキストファイルへの保存、クリップボード
    コピー、および Win32 GDI 直接印刷（Microsoft Print to PDF 含む）に
    対応しています。

3. 使い方
  1. WIB-GUI.exe を起動します（内蔵マニフェストにより管理者権限の確認
     ダイアログが表示されます）。
  2. 「バックアップ作成」タブで対象ドライブと保存先を選び、事前チェックに
     問題がないことを確認して「バックアップ開始」をクリックします。
  3. 完了後、「復元手順・印刷」タブから手順を印刷またはテキスト保存して
     手元に保管してください。

4. キーボード操作・スクリーンリーダー（NVDA / ナレーター）対応
  - Tab / Shift+Tab: 各コントロール間の移動。読み取り専用の複数行
    ログ欄や復元手順欄からも Tab / Shift+Tab でそのまま次へ移動できます。
  - Ctrl+Tab / Ctrl+Shift+Tab: タブ（バックアップ作成 / 既存バックアップ
    確認 / 復元手順・印刷）を切り替えます。
  - Alt+1〜3 または タブ見出しのアクセスキー: 各タブやボタン・入力欄へ
    アクセスキー（Alt + 英数字）で直接移動できます。
  - Ctrl+A: コマンドプレビュー欄、実行ログ欄、コマンド出力欄、復元手順
    本文欄で全文を選択できます。
  - 実行ログ欄を閲覧中（カーソルを末尾以外に置いた状態）に新しいログが
    追記されても、閲覧中の選択位置を維持します。

5. 注意事項・免責
  - Windows のシステムイメージ作成機能（wbadmin / WindowsImageBackup）は
    Microsoft により非推奨（レガシー機能）とされています。重要なデータの
    保護にはクラウドバックアップや他のバックアップ手段との併用もご検討
    ください。
  - ネットワーク共有フォルダへのバックアップは、Windows のエディションや
    アクセス権により制限される場合があり、通常は1世代のみの上書き保存に
    なります。また wbadmin の仕様上、資格情報を指定した場合は実行中
    プロセス引数として渡されます。
  - 本ソフトウェアの利用により生じたデータ損失等の損害について、作成者は
    責任を負いかねます。事前テストと複数手段での保管を推奨します。
