# WindowsImageBackup GUI (WIB-GUI) v0.2.0 取扱説明書

- 作成者: NRO / Antigravity


## 1. 概要
  WIB-GUI は、Windows 標準のシステムイメージ作成コマンド
  （C:\Windows\System32\wbadmin.exe）を、初心者やスクリーンリーダー
  利用者でも安全かつ分かりやすく操作できる、レジストリ不要・
  単一実行ファイル構成のポータブル Win32 GUI ツールです。

## 2. 主な機能・特徴
  - バックアップ作成（タブ1）:
    固定ドライブ一覧（DRIVE_FIXED）に容量・ファイルシステム・物理ディスク
    番号付き種別を表示し、対象ドライブを複数選択できます（システムドライブは
    既定でチェック済み）。「再スキャン」時は既存の選択状態を維持します。
    保存先としてローカル NTFS ドライブ、またはネットワーク共有フォルダ
    （\\Server\Share + 任意の資格情報 + パスワード「表示」切替 +
    モダンフォルダ選択ダイアログ）を指定できます。
    実行前に「対象と保存先の同一ドライブ」「同一物理ディスク」「非NTFS」
    および「対象使用量目安に対する保存先空き容量不足」を自動検出し、
    色分けバナー・コマンドプレビュー（パスワードマスク表示）・「いいえ」既定の
    確認ダイアログを表示します。
    バックアップ実行中は SetThreadExecutionState によりスリープを抑止し、
    準備中のマーキー表示・進捗率・経過時間・ウィンドウタイトル進捗・
    実行ログをリアルタイム表示します。「ログを保存」で UTF-8（BOM付き）
    保存ができ、中断時は wbadmin stop job -quiet で安全に停止します。

  - 既存バックアップ確認（タブ2）:
    指定した保存先にある作成済みシステムイメージ（wbadmin get versions）を
    日本語・英語 OS 両対応で解析して一覧表示します。
    ローカル／ネットワーク共有（参照・パスワード表示対応）や
    「バックアップタブの保存先を反映」ボタンから保存先を指定でき、
    取得後は先頭項目を自動選択します。バージョン識別子のコピーや、
    ダブルクリック／Enter／ボタンによる「復元手順・印刷」タブへの
    ワンクリック反映が可能です。

  - 復元手順・印刷（タブ3）:
    稼働中の Windows 上からは OS 本体の復元ができない旨の重要注意、
    WinRE GUI ウィザード手順、diskpart list volume によるドライブレター
    確認と保存先ドライブを反映した wbadmin start sysrecovery コマンド手順、
    .vhdx マウントによる個別ファイル復元手順、BitLocker 回復キーの注意を
    表示します。「保存先を反映」でタブ1の保存先もすぐに取り込めます。
    復元手順は UTF-8（BOM付き）テキストファイルへの保存、クリップボード
    コピー、およびページ番号・余白付きの Win32 GDI 直接印刷
    （Microsoft Print to PDF 含む）に対応しています。

  - 視認性・高DPI・ハイコントラスト対応:
    BIZ UDPゴシック／BIZ UDゴシック（等幅）フォント、白基調ペイン、
    下部2分割ステータスバー、PerMonitorV2 高DPI・ウィンドウリサイズ時の
    列幅自動調整に対応しています。Windows のハイコントラスト設定が有効な
    場合は自動的に標準システム配色へ切り替わります。

## 3. 使い方
  1. WIB-GUI.exe を起動します（内蔵マニフェストにより管理者権限の確認
     ダイアログが表示されます）。
  2. 「バックアップ作成」タブで対象ドライブと保存先を選び、事前チェックに
     問題がないことを確認して「バックアップ開始」をクリックします。
  3. 完了後、「復元手順・印刷」タブから手順を印刷またはテキスト保存して
     手元に保管してください。

## 4. キーボード操作・スクリーンリーダー（NVDA / ナレーター）対応
  - Tab / Shift+Tab: 各コントロール間の移動。読み取り専用の複数行
    ログ欄や復元手順欄からも Tab / Shift+Tab でそのまま次へ移動できます。
  - Ctrl+Tab / Ctrl+Shift+Tab: タブ（バックアップ作成 / 既存バックアップ
    確認 / 復元手順・印刷）を切り替えます。
  - Alt+1〜3 または アクセスキー（Alt + 英数字）: 各タブへ直接切替、
    または各ボタン・入力欄へ移動できます。
  - F5: 「バックアップ作成」タブではドライブ再スキャン、「既存バックアップ
    確認」タブでは一覧取得を実行します（非実行時）。
  - Enter（一覧上）: 「既存バックアップ確認」タブで選択中のバージョンを
    復元手順タブへ反映します。
  - Ctrl+S / Ctrl+P: 「復元手順・印刷」タブで手順の保存 / 印刷を行います。
  - Ctrl+A: コマンドプレビュー欄、実行ログ欄、コマンド出力欄、復元手順
    本文欄で全文を選択できます。
  - 実行ログ欄を閲覧中（カーソルを末尾以外に置いた状態）に新しいログが
    追記されても、閲覧中の選択位置を維持します。

## 5. 注意事項・免責
  - Windows のシステムイメージ作成機能（wbadmin / WindowsImageBackup）は
    Microsoft により非推奨（レガシー機能）とされています。重要なデータの
    保護にはクラウドバックアップや他のバックアップ手段との併用もご検討
    ください。
  - ネットワーク共有フォルダへのバックアップは、Windows のエディションや
    アクセス権により制限される場合があり、通常は1世代のみの上書き保存に
    なります。また wbadmin の仕様上、資格情報を指定した場合は実行中
    プロセス引数として渡されます。
  - 本ソフトウェアの利用により生じたデータ損失等の損害について、作成者は
    責任を負いかねます。事前テストと複数手段での保管を推奨します。
